# Qadam

A task and habit tracker website. Midterm project for Web Technologies 1 (Front End), AITU, group SE-2526.

**Live site:** https://nurlan-byte.github.io/qadam/

## Features

- Six pages: Home, Today, Calendar, Habits, Focus, Countdown, connected by one navigation menu
- Dark theme on CSS custom properties, Bootstrap 5 grid and utility classes
- Flexbox (task rows, habit cards, features) and CSS Grid (week calendar, streak grids)
- Positioning: sticky sidebar, absolute calendar events, fixed timer bar
- Two tables: month calendar and week overview of habits
- One form with text, date, time, select, textarea and checkbox fields
- Media queries at 992px and 576px: the sidebar becomes a burger menu, the week calendar becomes a single day
